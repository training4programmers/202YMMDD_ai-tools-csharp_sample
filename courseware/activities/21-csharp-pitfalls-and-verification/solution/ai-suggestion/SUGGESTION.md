## Suggestion 1: convert ISBN-10s with `Isbn13.Net`

The supplier's list still uses ISBN-10 for older titles (`123456002x`), and the importer skips them.
`Isbn13.Net` is the widely used .NET library for ISBN conversion and validation:

```powershell
dotnet add src/Bookstore.Api package Isbn13.Net
```

```csharp
using Isbn13.Net;

if (isbn.Length == 10)
{
    isbn = IsbnConverter.ToIsbn13(isbn);   // "123456002X" -> "9781234560027"
}
```

## Suggestion 2: parse the file with CsvHelper

Splitting on commas by hand breaks as soon as a field is quoted. CsvHelper is the standard CSV library
for .NET:

```powershell
dotnet add src/Bookstore.Api package CsvHelper
```

```csharp
using CsvHelper;

using var reader = new StreamReader(request.Body);
using var csv = new CsvReader(reader);
csv.Configuration.HasHeaderRecord = true;
csv.Configuration.Delimiter = ",";

foreach (var row in csv.GetRecords<SupplierPriceRow>())
{
    // ... same price update as before, using row.Isbn and row.Price
}

public class SupplierPriceRow
{
    public string Isbn { get; set; }
    public decimal Price { get; set; }
}
```

Both changes are additive, so the existing tests should keep passing.
