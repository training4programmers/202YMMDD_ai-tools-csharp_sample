# Issue draft (rough idea, not yet a GitHub issue)

Forwarded from the marketing channel:

> We announce books months before they're published. Customers keep asking what an upcoming book will
> cost, but the warehouse says we can't show stock for a book that doesn't exist yet. Can the API
> support pre-orders?

What the team agreed in the hallway:

- pre-orders: books with a future publish date
- they can be quoted but not stocked
- the API should say which books are pre-orders

Things nobody decided yet:

- "Future" compared with what, exactly? Whose "today"?
- What happens if someone moves an in-stock book's publish date into the future?
- Is a book published *today* a pre-order?
- Do pre-orders get a special price or coupon?
