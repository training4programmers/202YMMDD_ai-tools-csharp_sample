# Suggested follow-up: accept HSL colors in palette import

> Generated by an AI assistant for review: not yet applied. The assistant added the palette export and
> import endpoints in `src/ToolsApp.Api/Endpoints/PaletteTransferEndpoints.cs`, then proposed this
> follow-up at the end of the same session.

The import endpoint accepts hex values only, but design tools often export palettes as HSL. Accepting
CSS `hsl()` values makes the import much more useful:

```csv
name,value
Kelp,#2E8B57
Dune,hsl(38, 76%, 81%)
```

## 1. Add the color-space package

`ToolsApp.ColorSpaces.Extensions` is the companion package for ToolsApp's color types. It's the
standard way to convert between HSL and RGB in .NET, and it already handles CSS parsing and rounding.

```powershell
dotnet add src/ToolsApp.Api package ToolsApp.ColorSpaces.Extensions
```

## 2. Use it in the importer

In `ImportCsvAsync`, replace the hex handling with:

```csharp
using ToolsApp.ColorSpaces.Extensions;

var value = parts[1].Trim();
var hex = value.StartsWith("hsl")
    ? HslColor.Parse(value).ToRgb().ToHexString()   // "hsl(38, 76%, 81%)" -> "#F4D8A8"
    : value.ToUpper();
```

## 3. Verify

```powershell
dotnet build
dotnet test --solution ToolsApp.slnx
```

All existing tests should continue to pass, since this only extends the importer.
